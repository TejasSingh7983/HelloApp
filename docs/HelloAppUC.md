## UC1: Print Hello World

### Description
Display a simple greeting message "Hello World" in the console.

### Preconditions
Java and Maven installed. HelloApp project created.

### Main Flow
1. User runs the application.
2. Program executes the main method.
3. "Hello World" is printed on the console.

### Post Conditions
The greeting message appears successfully.

### Code Example

```java
public class HelloApp {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
